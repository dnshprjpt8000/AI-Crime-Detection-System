# Problem Statement

Traditional CCTV systems rely heavily on human monitoring. Continuous observation of multiple camera feeds is difficult and can result in delayed detection of suspicious activities.

This project aims to develop an AI-Powered Smart Surveillance and Crime Detection System capable of automatically detecting people, tracking their movement, identifying unauthorized access to restricted areas, and generating real-time alerts.

# Scope of the Project

The system focuses on surveillance automation using computer vision techniques. It detects and tracks people in video streams, monitors restricted zones, logs intrusion events, captures screenshots as evidence, and provides a dashboard for viewing intrusion records.

# Target Users

- Security Personnel
- Educational Institutions
- Office Buildings
- Shopping Malls
- Residential Communities

# High-Level Features

1. Person Detection using YOLOv8.
2. Person Tracking with unique IDs.
3. Person Counting in video streams.
4. Restricted Zone Monitoring.
5. Intrusion Detection and Alert Generation.
6. Event Logging in CSV format.
7. Screenshot Capture for evidence.
8. Dashboard for monitoring intrusion events.
